## Effect

Increases any existing critical skill given by equipment by 20 % for each skill level.

## Requirements per skill level

No requirements: any skill point can go here.

<p class="verified">Verified against v0.8.18 game code (`SkillCollection.java`).</p>

## Unlocks

- [Better Criticals](betterCriticals.md): needs this skill at level 1
- [Internal bleeding](crit1.md): needs this skill at level 2
- [Fracture](crit2.md): needs this skill at level 4
