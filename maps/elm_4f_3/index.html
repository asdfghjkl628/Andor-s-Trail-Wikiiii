    Elm 4f 3¶
    Map ID elm_4f_3
    Type Indoors / underground
    Size 15×20 tiles
    World map Elm 4f
    Introduced v0.7.14
    Enemy types 11
    Quests 0

    Elm 4f 3 is an indoor map. It has no NPCs and 11 kinds of enemy. Exits lead to Elm 4f 4, Elm 4f 2, Elm 4f 5.
