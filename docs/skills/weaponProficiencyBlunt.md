# Blunt weapon proficiency

*For each skill level, increases attack chance of blunt weapons by 30 % of the item's base attack chance, increases block chance by 30 % of the item's base block…*

**Category:** proficiency · **Max level:** 3 · **Obtained via:** First level from a quest, then skill points

## Description

For each skill level, increases attack chance of blunt weapons by 30 % of the item's base attack chance, increases block chance by 30 % of the item's base block chance, and increases critical skill by 10 % of the item's base critical skill. This includes clubs, quarterstaves, maces, scepters, whips, war hammers and giant hammers.

## Where to learn it

Granted by an NPC as part of: [Destined for great things](../quests/charwood1.md)
