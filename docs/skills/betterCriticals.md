# Better Criticals

*Increases any existing critical multiplier given by equipment by 25 % for each skill level.*

**Category:** criticals · **Max level:** unlimited · **Obtained via:** Skill points

## Requirements

- [More Criticals](../skills/moreCriticals.md) level 1 (each further level needs 1 more)

## Unlocks

Points spent here also count toward:

- [Internal bleeding](../skills/crit1.md) (needs this skill at level 2)
- [Fracture](../skills/crit2.md) (needs this skill at level 4)

## Description

Increases any existing critical multiplier given by equipment by 25 % for each skill level.
